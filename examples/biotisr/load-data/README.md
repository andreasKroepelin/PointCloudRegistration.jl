# Load data for BioTISR example

Run
```sh
julia --project=. load-data.jl
```

Optionally, you can download
https://zenodo.org/records/13843670/files/BioTISR_Mitochondria.zip
into this directory first if you can obtain it via some faster method
(such as [Varia](https://giantpinkrobots.github.io/varia/)).
